# Components

`Navigation` owns desktop and mobile navigation. `PageHero`, `SectionHeading`, `ButtonLink` and `FinalCta` establish page rhythm. `ServiceList` and `ServiceGroups` render `services.ts`; `ProjectGrid` and `PortfolioBrowser` render `portfolio.ts`. `EnquiryForm` owns interactive state and `/api/enquiry` owns server delivery. Preserve native controls, visible focus and semantic links. Do not duplicate record markup.
