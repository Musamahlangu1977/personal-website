# Deployment

Deploy to Vercel with `pnpm build`. Configure `NEXT_PUBLIC_SITE_URL`, `SITE_INDEXABLE`, `ENQUIRY_WEBHOOK_URL` and optional `ENQUIRY_WEBHOOK_TOKEN`. Never prefix secrets with `NEXT_PUBLIC_`.

Before launch: test enquiry delivery, complete legal review, replace the founder portrait placeholder, confirm social links and Kori website scope, review portfolio permissions, and add only verified client reviews. Then enable indexing and submit the sitemap.
